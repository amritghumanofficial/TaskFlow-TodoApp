# 🚀 TaskFlow — Todo App

A modern and responsive Todo App built with HTML, CSS, and JavaScript to help users manage daily tasks efficiently.

🔗 **Live Demo:** [https://amritghumanofficial.github.io/TaskFlow-TodoApp/](https://amritghumanofficial.github.io/TaskFlow-TodoApp/)

---

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete individual tasks
- 🧹 Clear all tasks
- ⏳ Track tasks as Pending
- ⚡ Track tasks as In Progress
- ✅ Track tasks as Completed
- 🔄 Change task status by clicking on the task
- 🌙 Dark Mode
- 💾 Tasks are saved using Browser LocalStorage
- 📊 Real-time task statistics
- 📱 Responsive user interface
- ⌨️ Add tasks using the Enter key

---

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling, responsive layout and dark mode
- **JavaScript** — Task management and application logic
- **LocalStorage** — Persistent task and theme storage

---

## 📊 Task Statistics

TaskFlow provides real-time statistics for:

| Statistic | Description |
|-----------|-------------|
| Total | Total number of tasks |
| Pending | Tasks waiting to be started |
| In Progress | Tasks currently being worked on |
| Done | Completed tasks |

## 💾 LocalStorage

TaskFlow uses the browser's LocalStorage API to save:

- User tasks
- Task statuses
- Dark mode preference

This means your tasks remain available even after refreshing or reopening the browser on the same device/browser.

---

## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/amritghumanofficial/TaskFlow-TodoApp.git
   ```

2. Open the project folder:
   ```bash
   cd TaskFlow-TodoApp
   ```

3. Then open `index.html` in your browser.

No backend or external dependencies are required.
